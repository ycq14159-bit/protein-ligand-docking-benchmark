# Metric definition lock — 2026-08-28 revision

## CATH

`Unique CATH IDs` means unique valid four-level CATH H-level classifications (`C.A.T.H`). Null/unannotated is never an ID. CROWN expected harmonized value is 2,040; website 2,041 is `CROWN_REPORTED_ONLY`.

## Historical reported ion/artifact statistics

PLINDER Ion=22,728 and Artifact=18,626 from the CROWN website are `CROWN_REPORTED_ONLY`. No trial combination of filters is used to force reproduction.

## Formal ligand taxonomy

The formal paper comparison uses `comparison_ligand_taxonomy_v1` over every Mode B entry: monoatomic ion, simple inorganic, and direct normalized CCD match to one frozen shared artifact list. Artifact-list membership is an overlapping label, not a mutually exclusive class.

All annotations are retrospective and do not change database membership.
